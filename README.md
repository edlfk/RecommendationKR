# RecommendationKR  
**Серверная часть системы рекомендаций контента**

## Описание
Данный репозиторий содержит серверную часть интернет-ресурса, реализующего систему персонализированных рекомендаций контента. Серверная часть разработана в рамках курсовой работы по дисциплине *Проектирование и разработка серверных частей интернет-ресурсов*.

Система предоставляет REST API для:
- сохранения и обновления профилей пользователей;
- хранения интересов пользователей;
- генерации рекомендаций контента на основе тегов и интересов;
- получения информации о конкретном контенте.

Архитектура решения построена на основе упрощённого паттерна **MVC**, ориентированного на прозрачность логики и удобство анализа алгоритмов рекомендаций.

---

## Основной функционал
- сохранение профиля пользователя (возраст, пол, интересы);
- обновление профиля пользователя;
- хранение интересов в формате JSONB;
- генерация рекомендаций на основе пересечения интересов пользователя и тегов контента;
- сортировка рекомендаций по популярности;
- предоставление данных через REST API в формате JSON;
- модульное и API-тестирование.

## Архитектура
Серверная часть реализована на основе упрощённого паттерна **MVC**:

- **Controller**  
  Обрабатывает HTTP-запросы, выполняет валидацию входных данных, реализует бизнес-логику и формирует JSON-ответы.

- **Model**  
  Представлена структурой базы данных PostgreSQL и SQL-запросами, выполняемыми через PDO.

- **View**  
  Реализована в виде JSON-ответов REST API. Визуальное представление вынесено на клиентскую сторону.

Маршрутизация запросов осуществляется через единый файл точки входа.

---

## Структура проекта
`public/` — публичная директория и точка входа приложения  
`public/index.php` — маршрутизация запросов и запуск приложения  

`src/` — исходный код серверной части  
`src/Config/` — конфигурация приложения  
`src/Controller/` — контроллеры обработки HTTP-запросов  
`src/Database/` — класс подключения к базе данных (PDO)  
`src/Model/` — логическая модель данных (профили, контент)  
`src/Repository/` — слой доступа к данным  
`src/Service/` — сервисный слой (алгоритмы рекомендаций)  
`src/App.php` — инициализация приложения  

`migrations/` — SQL-скрипты создания и наполнения базы данных  
`migrations/schema.sql` — структура базы данных  
`migrations/seed.sql` — тестовые данные  

`tests/` — автоматические тесты  
`tests/ApiEndpointsTest.php` — тестирование REST API  
`tests/RecommendationControllerTest.php` — тестирование логики рекомендаций  

`docker-compose.yml` — конфигурация запуска контейнеров  
`nginx/default.conf` — конфигурация веб-сервера  
`composer.json` — зависимости проекта  
`phpunit.xml` — конфигурация тестирования  
`.env` — переменные окружения

## База данных
Для хранения данных используется **PostgreSQL**.

- интересы пользователей и теги контента хранятся в формате **JSONB**;
- для ускорения поиска пересечений используются **GIN-индексы**;
- рекомендации формируются на основе пересечения JSONB-массивов интересов и тегов контента.

---

## API эндпоинты

Пример:

### Сохранение профиля пользователя
`POST /profile`

Пример тела запроса:
```json
{
  "user_id": 1,
  "age": 25,
  "gender": "мужской",
  "interests": ["IT", "кино", "игры"]
}
```
Ответ:
```json
{
  "status": "ok"
}
```

## Тестирование

Для тестирования серверной части используется **PHPUnit**.

Проверяются:

- корректность работы API;
- обработка ошибок;
- генерация рекомендаций;
- сохранение профилей пользователей.

**Запуск тестов:**
```bash
docker compose exec app vendor/bin/phpunit
```

